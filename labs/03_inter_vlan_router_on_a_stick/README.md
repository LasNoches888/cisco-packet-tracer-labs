# Лаба 03 — Router-on-a-stick

## Цель
Настроить маршрутизацию между VLAN через один физический интерфейс маршрутизатора (сабинтерфейсы 802.1Q).
Лаба продолжает [лабу 02](../02_vlans_and_trunking): та же схема VLAN, но добавляется маршрутизатор.

## Топология
```
PC1 (VLAN10) --[SW1]--Gi0/2 ===== trunk ===== Gi0/0 [R1]
PC3 (VLAN20) --[SW1]
```
Оборудование: 1 × маршрутизатор 2911, 1 × коммутатор 2960, 2 × PC.

## Адресация

| Устройство | Интерфейс | VLAN | IP-адрес | Шлюз |
|------------|-----------|------|----------|------|
| R1 | Gi0/0.10 | 10 | 192.168.10.1/24 | — |
| R1 | Gi0/0.20 | 20 | 192.168.20.1/24 | — |
| R1 | Gi0/0.99 (native) | 99 | 192.168.99.1/24 | — |
| PC1 | NIC | 10 | 192.168.10.11/24 | 192.168.10.1 |
| PC3 | NIC | 20 | 192.168.20.11/24 | 192.168.20.1 |
| SW1 | Vlan99 | 99 | 192.168.99.11/24 | 192.168.99.1 |

## Настройка
Конфиги: [`R1.cfg`](R1.cfg), [`SW1.cfg`](SW1.cfg).

Ключевые моменты:
- физический интерфейс `Gi0/0` остаётся без IP-адреса и включён (`no shutdown`);
- каждому сабинтерфейсу назначается VLAN командой `encapsulation dot1Q <vlan>`;
- для native VLAN используется `encapsulation dot1Q 99 native` — иначе нетегированный трафик не попадёт ни в один сабинтерфейс;
- порт коммутатора в сторону маршрутизатора — trunk с теми же allowed/native VLAN.

## Проверка
```
R1# show ip interface brief
R1# show ip route connected
R1# show interfaces GigabitEthernet0/0.10
PC1> ping 192.168.10.1
PC1> ping 192.168.20.11      # теперь успешно, трафик идёт через R1
PC1> tracert 192.168.20.11   # два хопа: 192.168.10.1 → цель
```
Ожидаемый результат: в таблице маршрутизации три connected-сети (`C`) и три локальных адреса (`L`),
ping между VLAN 10 и VLAN 20 проходит.

## Для самостоятельной работы
1. Добавьте VLAN 30 (`192.168.30.0/24`) и сабинтерфейс `Gi0/0.30`.
2. Запретите доступ из VLAN 10 в VLAN 20 с помощью расширенного ACL на `Gi0/0.10` (`ip access-group … in`),
   оставив доступ к шлюзу. Проверьте счётчики `show access-lists`.
3. Сравните с подходом L3-коммутатора (SVI + `ip routing`): в чём преимущества и ограничения router-on-a-stick?
