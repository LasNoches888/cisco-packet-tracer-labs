# Методика поиска неисправностей

Идём снизу вверх по модели OSI и не переходим на следующий уровень, пока не убедились, что текущий в порядке.

## 1. Физический уровень
- Лампочки линка (в Packet Tracer — зелёные треугольники) горят у обоих концов кабеля?
- Тип кабеля верный? Одинаковые устройства (коммутатор–коммутатор, маршрутизатор–PC) — кроссовер, разные — прямой.
- Интерфейс не в `administratively down`? → `no shutdown`.

Проверка: `show ip interface brief`, `show interfaces status`.

## 2. Канальный уровень
- Порт в нужном VLAN? → `show vlan brief`.
- Trunk поднялся, нужные VLAN в `allowed`? → `show interfaces trunk`.
- Совпадает native VLAN на двух концах trunk?
- MAC-адрес хоста виден на правильном порту? → `show mac address-table`.

## 3. Сетевой уровень
- Адрес, маска и шлюз на хосте верны? Шлюз находится в той же подсети, что и хост?
- Маршрут до цели есть? → `show ip route`.
- Есть **обратный** маршрут? Ping «в одну сторону» — частая причина «не работает» (проверьте `ping … source`).
- Нет ли ACL, режущего трафик? → `show access-lists`, `show ip interface <int>` (раздел access list).
- Для OSPF: соседства в `FULL`? Совпадают area, hello/dead-таймеры, маски подсетей? → `show ip ospf neighbor`.

## 4. Прикладные сервисы
- DHCP: пул не исчерпан, не пересекается со статическими адресами → `show ip dhcp pool`.
- NAT: корректно ли указаны `inside`/`outside` и ACL → `show ip nat statistics`.

## Типовые симптомы

| Симптом | Вероятная причина |
|---------|-------------------|
| Первый ping теряется, остальные идут | ARP-запрос на первом пакете — норма |
| `Destination host unreachable` от шлюза | нет маршрута до сети назначения на маршрутизаторе |
| `Request timed out` на всех пакетах | нет обратного маршрута, ACL или NAT; проверить обе стороны |
| VLAN есть, но хосты не видят друг друга через trunk | VLAN отсутствует в `allowed vlan` или не создан на втором коммутаторе |
| OSPF-сосед застрял в `INIT` / `EXSTART` | несовпадение MTU, аутентификации или односторонняя связность |
| Хост получил адрес `169.254.x.x` | DHCP-сервер недоступен (нет линка, VLAN, `ip helper-address`) |
