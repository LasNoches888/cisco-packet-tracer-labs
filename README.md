# cisco-packet-tracer-labs

Пошаговые лабораторные по Cisco IOS для Cisco Packet Tracer (подходят и для GNS3/EVE-NG).
В каждой лабе: цель, топология, таблица адресации, готовые конфиги и команды проверки.

## Лабораторные

| # | Лаба | Что отрабатываем |
|---|------|------------------|
| 01 | [Базовая связность](labs/01_basic_connectivity) | интерфейсы, IP-адресация, ping между двумя LAN через маршрутизатор |
| 02 | [VLAN и trunk](labs/02_vlans_and_trunking) | VLAN 10/20/99, access/trunk-порты, native VLAN, SVI управления |
| 03 | [Router-on-a-stick](labs/03_inter_vlan_router_on_a_stick) | маршрутизация между VLAN через сабинтерфейсы 802.1Q |
| 04 | [OSPF, одна зона](labs/04_ospf_single_area) | соседства, router-id, passive-interface, переключение маршрута при обрыве |
| 05 | [DHCP и NAT](labs/05_dhcp_and_nat) | DHCP-пул, исключённые адреса, NAT overload (PAT), маршрут по умолчанию |

Рекомендуемый порядок — по возрастанию: каждая следующая лаба использует идеи предыдущей.

## Как работать с лабой

1. Соберите топологию в Packet Tracer по схеме из `README.md` нужной лабы.
2. Зайдите в CLI устройства (`enable` → `configure terminal`) и вставьте конфиг из файла `*.cfg`.
   Конфиги написаны так, чтобы их можно было вставлять целиком.
3. Выполните проверки из раздела «Проверка» и сравните с ожидаемым результатом.
4. Сохраните конфигурацию: `copy running-config startup-config`.
5. Попробуйте задания «Для самостоятельной работы» — без подсматривания в готовые конфиги.

## Связанные репозитории

- `netadmin-cisco-topologies` — готовые конфиги сетевых топологий.
- `netadmin-subnetting-vlsm-labs` — расчёт подсетей и VLSM.

> Адреса из диапазона `203.0.113.0/24` (TEST-NET-3, RFC 5737) используются как «внешняя» сеть:
> они зарезервированы для документации и не маршрутизируются в реальном интернете.
